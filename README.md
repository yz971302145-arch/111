【摆放与支撑】
· 地台：倾斜 10~15° 摆放；支撑只加在底面与侧面。
  凹槽内壁、顶面浮雕、底面防滑槽都不要加支撑。
· 人物：倾斜 10~20°；脚部重点加固。
  支撑必须避开脚底与脚的侧面 —— 这些面要插进凹槽。
· 人物脚底若留支撑疤，请打磨平整。
· 人物后背草帽的帽檐边缘最薄约 0.11mm（刀刃状收边），
  该处不要加支撑，取件时也请避开。

【精度】
· 两个件同一批打印、同一罐树脂，减少批次差异。
· 凹槽与鞋底实测最小侧向间隙 0.095mm（设计值 0.06mm），
  请勿额外放大或缩小任一模型。
· 人物前倾 0.8mm 落座属正常（鞋底与凹槽的配合基准），
  不要为了「居中」而强行挪动。

【后处理】
· 清洗时不要用硬毛刷去刷地台顶面的浮雕细线（线宽仅 0.30mm），
  也不要刷人物草帽的帽檐边缘。
· 二次固化后确认人物双脚能自然落入凹槽。

【验收】人物双脚能放入凹槽，插入后不晃动，可反复取出装入。
